# Segurança

O API Mock Station é uma ferramenta de laboratório local. A API administrativa não possui autenticação e não deve ser exposta publicamente. Execute em ambiente isolado e nunca carregue credenciais ou dados reais. O limite de payload não substitui um proxy seguro em produção.

Para reportar vulnerabilidades, evite issues públicas com detalhes exploráveis. Entre em contato com o mantenedor por canal privado do perfil GitHub. Não publique segredos nem informações de terceiros.
