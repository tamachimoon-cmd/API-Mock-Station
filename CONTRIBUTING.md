# Contribuindo

Obrigado por colaborar com o LAB//ABERTO. Abra uma issue para mudanças grandes antes de implementar. Crie uma branch de trabalho, mantenha mudanças pequenas e independentes e inclua testes para alterações de comportamento.

Execute `npm test` e `npm run check` antes de abrir um pull request. Não envie dados privados, credenciais, logs reais ou código de projetos corporativos. Mantenha exemplos inteiramente fictícios.
